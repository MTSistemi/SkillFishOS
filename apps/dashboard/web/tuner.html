🧩 CPU cores — live, no reboot

  

    – active cores
    
    
    
    
    
  

  

  

  
Each box = 1 physical core with its 2 threads. Core 0 always stays on: it hosts the boot CPU and the kernel cannot switch it off. Turning cores off frees thermal budget so the remaining ones clock higher. A reboot brings them all back.

  
Loads scx_lavd, a scheduler that lives inside the kernel and decides which task gets the CPU next. It does not make more frames: it makes them arrive more evenly. Measured with Wukong, the average did not move while the one per cent lows went up by a fifth. It needs a kernel built with sched_ext: without one the box stays off.

  
Physical core layout (for game affinity/pinning). Live MHz per core.
