SkillFishOS побудований на **Debian sid** (*unstable*) — гілці розробки Debian: завжди свіжій, але за самою природою схильній до випадкових регресій. На «екзотичному» залізі на кшталт BC-250 невдале оновлення (Mesa, мікропрограми чи ядра) здатне зламати систему. SkillFishOS дає цьому раду двома способами.

## 1. Власні складові з окремого репозиторію

Найкритичніші частини ми збираємо й поширюємо **самі**, з **власного підписаного репозиторію APT**:

- оптимізоване **[ядро](/uk/docs/kernel)** (образ + заголовки);
- **керівник SMU** й засоби розгону;
- **власні програми** [Tuner і AI](/uk/docs/app-native);
- **тема steampunk** і **оформлення марки**;
- налаштування системи.

Випускати складову з власного репозиторію означає, що ми можемо **спершу перевірити її** на справжньому залізі й оновити **лише тоді, коли це дає користь**, — а не щоразу, коли щось змінилося у джерела.

## 2. «Закріплення» крихких пакунків

Для пакунків, які надходять із Debian, але на цьому залізі є вразливими, SkillFishOS застосовує **закріплення APT**: тримає їх на **перевіреній** версії, доки ми не випробуємо новішу. Головні кандидати на закріплення:

- **Mesa / драйвери Vulkan (RADV)** — оновлення може зіпсувати підтримку `gfx1013`;
- **мікропрограми AMD / `linux-firmware`** — мікрокод графіки;
- **штатне ядро Debian** — щоб заблокувати версії, відомі проблемами (див. [ядро](/uk/docs/kernel));
- **KDE Plasma** — щоб уникати нестабільних випусків.

Завдяки цьому «звичайні» оновлення (себто більшість системи) надходять як завжди, а жменька пакунків, здатних усе зламати, лишається замороженою на версіях, про які ми знаємо, що вони працюють.

## Як оновлювати

Як у будь-якому Debian, із термінала:

```bash
sudo apt update && sudo apt full-upgrade
```

…або з графічної програми **Discover**, або з **SkillFishOS Hub** — нашого центру програм у дусі Discover, який встановлює, вилучає й оновлює в одному місці з **APT, Flatpak і Snap**, з переглядом за категоріями, сторінками програм із каруселлю знімків екрана та кнопкою «Оновити все». Завдяки зачепам [Snapper](/uk/docs/storage-snapshot) знімок Btrfs створюється **перед кожним оновленням і після нього**: якщо щось піде не так, повернення з меню GRUB відновить попередній стан.

> Коротко: **ми** даємо перевірене ядро, програми й теми; **Debian** дає решту свіжого програмного забезпечення; **закріплення** запобігає несподіванкам; **Btrfs** — сітка безпеки. Три шари захисту, щоб оновлюватися не було страшно.

## Офіційний репозиторій

Репозиторій APT SkillFishOS **працює**, підписаний GPG і розміщений на **GitHub Pages** (набір `aetherium`):

```bash
# 1. імпортуйте ключ підпису
sudo curl -fsSL https://mtsistemi.github.io/SkillFishOS/skillfishos-archive-keyring.gpg \
  -o /usr/share/keyrings/skillfishos-archive-keyring.gpg
# 2. додайте репозиторій
echo "deb [signed-by=/usr/share/keyrings/skillfishos-archive-keyring.gpg] \
https://mtsistemi.github.io/SkillFishOS aetherium main" \
  | sudo tee /etc/apt/sources.list.d/skillfishos.list
# 3. встановіть/оновіть ядро через apt
sudo apt update && sudo apt install skillfishos-kernel
```

Свіжі збірки SkillFishOS мають його **вже налаштованим**; інакше наведені команди його додадуть. [Ядро](/uk/docs/kernel) (образ на 152 МБ) публікується як *ресурс випуску* на GitHub: крихітний пакунок `skillfishos-kernel` звантажує та встановлює його самотужки, тож оновлення все одно йде через `apt`. Репозиторієм керує **[reprepro](https://salsa.debian.org/debian/reprepro)**, а клієнт перевіряє підпис окремим *сховищем ключів*.
