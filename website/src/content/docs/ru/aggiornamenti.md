SkillFishOS построен на **Debian sid** (*unstable*) — ветке разработки Debian: всегда свежая, но по своей природе иногда приносящая откаты назад. На необычном железе вроде BC-250 неудачное обновление (Mesa, прошивок или ядра) может сломать систему. SkillFishOS отвечает на это двумя средствами.

## 1. Свои составные части, из отдельного репозитория

Самое ответственное собираем и раздаём **мы сами**, из **собственного подписанного репозитория APT**:

- оптимизированное **[ядро](/ru/docs/kernel)** (образ и заголовки);
- **регулятор SMU** и средства разгона;
- **родные приложения** [Tuner и AI](/ru/docs/app-native);
- **стимпанк-оформление** и **фирменный стиль**;
- настройки системы.

Раздавать составную часть из своего репозитория означает, что мы можем **сначала её проверить** на настоящем железе и обновлять **только тогда, когда это приносит пользу**, а не всякий раз, когда что-то изменилось выше по течению.

## 2. «Закрепление» хрупких пакетов

Для пакетов, которые приходят из Debian, но на этом железе нежные, SkillFishOS использует **закрепление APT** (pinning): держит их на **проверенной** версии, пока мы не испытаем новую. Главные кандидаты на закрепление:

- **Mesa и драйверы Vulkan (RADV)** — обновление может испортить `gfx1013`;
- **прошивки AMD / `linux-firmware`** — микрокод видеоядра;
- **штатное ядро Debian** — чтобы заблокировать известные проблемные версии (см. [ядро](/ru/docs/kernel));
- **KDE Plasma** — чтобы не поймать нестабильный выпуск.

Так «обычные» обновления (большая часть системы) продолжают приходить как обычно, а горстка пакетов, способных сломать всё, остаётся на версиях, про которые мы знаем, что они работают.

## Как обновляться

Как на любой системе Debian, из терминала:

```bash
sudo apt update && sudo apt full-upgrade
```

…либо из графического приложения **Discover**, либо из **SkillFishOS Hub** — нашего центра программ в духе Discover, который ставит, удаляет и обновляет в одном месте через **APT, Flatpak и Snap**, с просмотром по категориям, страницами приложений с каруселью снимков экрана и кнопкой «Обновить всё». Благодаря перехватчикам [Snapper](/ru/docs/storage-snapshot) снимок Btrfs создаётся **до и после** каждого обновления: если что-то пойдёт не так, возврат из меню GRUB восстановит прежнее состояние.

> Коротко: **мы** даём проверенное ядро, приложения и оформление; **Debian** — всё остальное свежее программное обеспечение; **закрепление** не даёт случиться сюрпризам; **Btrfs** — страховочная сетка. Три слоя защиты, чтобы обновляться было не страшно.

## Официальный репозиторий

Репозиторий APT SkillFishOS **работает**, подписан GPG и живёт на **GitHub Pages** (набор `aetherium`):

```bash
# 1. ввозим ключ подписи
sudo curl -fsSL https://mtsistemi.github.io/SkillFishOS/skillfishos-archive-keyring.gpg \
  -o /usr/share/keyrings/skillfishos-archive-keyring.gpg
# 2. добавляем репозиторий
echo "deb [signed-by=/usr/share/keyrings/skillfishos-archive-keyring.gpg] \
https://mtsistemi.github.io/SkillFishOS aetherium main" \
  | sudo tee /etc/apt/sources.list.d/skillfishos.list
# 3. ставим или обновляем ядро через apt
sudo apt update && sudo apt install skillfishos-kernel
```

Свежие сборки SkillFishOS приходят с ним **уже настроенным**; в противном случае команды выше всё подготовят. [Ядро](/ru/docs/kernel) (образ на 152 МБ) публикуется как *release asset* на GitHub: крошечный пакет `skillfishos-kernel` сам его скачивает и устанавливает, так что обновление всё равно идёт через `apt`. Репозиторием заведует **[reprepro](https://salsa.debian.org/debian/reprepro)**, а клиент проверяет подпись по отдельному *keyring*.
